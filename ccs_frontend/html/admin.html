# Ország Rekordok

QSL kimutatás

Kimutatás letöltése

Résztvevőnkénti QSO-lista: dátum (UTC), sáv, mód, operátor. A már meglévő sáv-mód párosítás ismétlésnek számít, és nem számít bele az érvényes QSO-kba: a Word változatban az ilyen sor át van húzva, az Excel változatban külön oszlop jelöli.

Diplomát szerzettek: legalább 3 különböző (sáv, mód) párosítás. Összes QSO: mindenki, akinek van legalább egy összeköttetése.
